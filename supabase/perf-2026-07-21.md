### 2. Index for the fetchStats subscribed count

```sql

  ON public.subscribers (member_id, subscribed);
```

Verified: indisvalid = t. EXPLAIN ANALYZE of `SELECT count(*) ... WHERE member_id IS NULL AND subscribed = true` now runs as an Index Only Scan with Heap Fetches: 0, execution time 12.6ms.
